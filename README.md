# GrowthPilot AI

GrowthPilot AI is an autonomous, AI-powered B2B SEO and Content Generation agent. Designed to help e-commerce stores scale their organic growth automatically.

## Core Features

- **Automated Technical Audits**: Run in-depth SEO audits with automated insights generated by LLMs.
- **Google Search Console Integration**: Sync daily keyword performance metrics (Impressions, Clicks, CTR, Position).
- **Striking Distance Optimization**: Automatically identify and flag high-impression, page 2-4 keywords ("Low Hanging Fruit").
- **Content AI with EEAT Injection**: Generate complete, SEO-optimized blog posts with real company context and brand assets (Experience, Expertise, Authoritativeness, and Trustworthiness) automatically injected into the AI prompt.
- **Autonomous Blog Agent**: A fully automated background worker that continually analyzes keyword performance and triggers new content generation.

## Getting Started Locally

### 1. Requirements
- Node.js 22+
- Docker & Docker Compose (for local PostgreSQL and Redis)

### 2. Setup environment
Copy the `.env.example` file to `.env.local`:
```bash
cp .env.example .env.local
```
Fill in the necessary credentials, particularly your `QWEN_API_KEY` and Google OAuth credentials (`GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`).

### 3. Start Infra
```bash
docker-compose up -d
```
This spins up local Postgres and Redis.

### 4. Install & Run
```bash
npm install --legacy-peer-deps
npm run db:push
npm run dev
```

### 5. Run Background Workers
The system relies on background workers for crawling, GSC sync, and automated blog generation.
Open a separate terminal and run:
```bash
npm run worker:audit
npm run worker:blog
npm run worker:gsc
```
